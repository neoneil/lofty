# Lofty Course Design Guide

> Lofty Course Design Guide v1.0

本文档定义 Lofty 课程的设计规范。AI 在生成课程时，应优先遵循本规范，再按照《Markdown Specification》输出最终 Markdown。

---

# 一、设计原则

Lofty 课程强调：

* 简洁
* 易读
* 可视化
* 循序渐进
* 一个知识点解决一个问题

课程不是教材，也不是论文，而是帮助学生快速理解和掌握知识。

---

# 二、AI 工作流程

收到用户提供的内容（Word、PDF、PPT、教材、课堂笔记、录音等）后，应按以下步骤处理：

1. 阅读全部内容，理解主题。
2. 提炼核心知识点。
3. 删除重复、冗余内容。
4. 按学习顺序重新组织。
5. 拆分为多个 Slide。
6. 使用 Markdown Specification 输出最终课程。

严禁直接复制原文。

---

# 三、Slide 设计原则

每个 Slide 只讲一个知识点。

推荐结构：

```text
标题

↓

一句概括

↓

重点说明

↓

例子

↓

总结
```

避免：

* 一页内容过多
* 大段连续文字
* 多个知识点混在一起

---

# 四、课程结构建议

一节课程建议按照以下顺序组织：

1. 课程介绍
2. 学习目标（GOAL）
3. 知识点讲解
4. 示例（Example）
5. 考试技巧（Tip / Keypoint）
6. 常见错误（Common Mistake）
7. 总结（Summary）
8. 作业（Homework）

可根据课程内容适当调整。

---

# 五、Admonition 使用建议

根据内容选择对应卡片：

* GOAL：学习目标
* KEYPOINT：考试重点
* TIP：技巧
* NOTE：补充说明
* WARNING：注意事项
* COMMON-MISTAKE：常见错误
* EXAMPLE：案例
* SUMMARY：课程总结
* HOMEWORK：课后练习

不要滥用卡片，每张 Slide 建议 1～2 个即可。

---

# 六、Highlight 与颜色

以下内容建议使用 Highlight：

* 核心定义
* 考试重点
* 必须记忆的规则
* 最终结论

彩色文字建议：

* 红色：错误表达、警告
* 绿色：正确表达
* 黄色：考试重点
* 蓝色：知识点
* 紫色：高级表达或拓展内容

避免整段文字全部使用颜色。

---

# 七、示例设计

尽量为每个知识点提供示例。

优先顺序：

1. 简单例子
2. 考试例子
3. 对比例子
4. 易错例子

例子应尽量贴近真实考试或实际使用场景。

---

# 八、课程节奏

建议遵循：

* 从简单到复杂
* 从概念到应用
* 从规则到练习

不要一开始讲复杂内容。

每完成一个知识点，再进入下一个知识点。

---

# 九、Homework 设计

课程结尾建议安排课后练习。

推荐包含：

* 阅读
* 练习
* 录音
* 复习
* 自我检查

例如：

```markdown
> [!HOMEWORK]
> - [ ] 完成练习 1～5
> - [ ] 录音一次
> - [ ] 回听并找出三个问题
```

---

# 十、AI 输出要求

AI 最终输出的课程应满足以下要求：

* 符合《Markdown design guide》。
* 内容逻辑清晰。
* Slide 数量合理 一版在10页到30页之间。
* 一个 Slide 一个知识点 （开头可增加适当的引言slide）。
* 自动补充必要的 GOAL、KEYPOINT、SUMMARY、HOMEWORK。
* 自动添加适当的 Highlight、颜色和 Badge。
* 保持统一的 Lofty 风格。

最终生成的 Markdown 应可直接保存为 `.md` 文件，可以导入 Lofty 系统，无需人工修改。
