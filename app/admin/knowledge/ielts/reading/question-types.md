# 雅思阅读题型与六大技巧分类

这份材料用于课堂讲解 IELTS Reading 的题型框架。学生不需要把雅思阅读学成十四套互不相关的方法，而是要先看清题型之间的共同能力，再把训练压缩成更稳定、更可执行的技巧体系。

## 一、雅思阅读 14 类常见题型

| # | 雅思阅读题型 | 英文官方名称 | 我们平时简称 |
| ---: | --- | --- | --- |
| 1 | 判断事实 | True / False / Not Given | **TFNG** |
| 2 | 判断作者观点 | Yes / No / Not Given | **YNNG** |
| 3 | 段落标题匹配 | Matching Headings | **Heading** |
| 4 | 信息定位到段落 | Matching Information | **段落信息匹配** |
| 5 | 人物/事物特征匹配 | Matching Features | **人名/特征匹配** |
| 6 | 句子结尾匹配 | Matching Sentence Endings | **句尾匹配** |
| 7 | 单选题 | Multiple Choice - single answer | **单选** |
| 8 | 多选题 | Multiple Choice - multiple answers | **多选** |
| 9 | 句子填空 | Sentence Completion | **句子填空** |
| 10 | Summary 填空 | Summary Completion | **摘要填空** |
| 11 | Notes 填空 | Note Completion | **笔记填空** |
| 12 | Table 填空 | Table Completion | **表格填空** |
| 13 | Flow-chart / Diagram | Flow-chart / Diagram Label Completion | **流程图/图示填空** |
| 14 | 简答题 | Short-answer Questions | **简答题** |

## 二、小马哥建议：不要真的学“14套方法”

课堂上更建议把技巧压缩成 **6 大类**。这样学生更容易形成稳定的做题流程，也更容易迁移到不同文章和不同 Cambridge 真题里。

| 大类 | 包含题型 | 核心能力 |
| --- | --- | --- |
| **1. 判断题** | TFNG、YNNG | 定位 + 同义替换 + 判断矛盾/缺失 |
| **2. 段落匹配** | Matching Headings、Matching Information | 主旨 vs 细节 |
| **3. 特征匹配** | Matching Features | 人名/理论/事物定位 |
| **4. 选择题** | 单选、多选、Sentence Endings | 定位 + 排除 |
| **5. 填空题** | Sentence / Summary / Note / Table / Flow-chart / Diagram | 定位 + 词性 + 原文词 |
| **6. 简答题** | Short Answer | 定位 + 字数限制 |

> 这才是我们课堂里真正需要的 **“雅思阅读按题型技巧总结”**。

## 三、客观题与主观题

IELTS Reading 的题型还可以按答案形式分成客观题和主观题。这个分类很重要，因为它决定学生训练时到底是在练“选项判断”，还是在练“原文取词”。

| 分类 | IELTS Reading 题型 | 答案形式 |
| --- | --- | --- |
| **客观题** | 1. True / False / Not Given | TRUE / FALSE / NOT GIVEN |
| **客观题** | 2. Yes / No / Not Given | YES / NO / NOT GIVEN |
| **客观题** | 3. Matching Headings | 选标题字母/罗马数字 |
| **客观题** | 4. Matching Information | 选段落字母 |
| **客观题** | 5. Matching Features | 选人物/事物对应字母 |
| **客观题** | 6. Matching Sentence Endings | 选句尾 A/B/C... |
| **客观题** | 7. Multiple Choice - Single Answer | 单选 A/B/C/D |
| **客观题** | 8. Multiple Choice - Multiple Answers | 多选 A/B/C/D... |
| **主观题** | 9. Sentence Completion | 自己从原文找词填 |
| **主观题** | 10. Summary Completion | 自己填词* |
| **主观题** | 11. Note Completion | 自己填词* |
| **主观题** | 12. Table Completion | 自己填词* |
| **主观题** | 13. Flow-chart / Diagram Label Completion | 自己填词* |
| **主观题** | 14. Short-answer Questions | 自己写答案 |
